Requirement 3.2 — Inheritance & Polymorphism

Task types and class hierarchy

The assignment required a base Task class with at least three derived subclasses, each extending base behaviours where appropriate.

Assignment says: "A base Task class must be implemented, with at least three derived classes: DeadlineTask (includes a deadline attribute), PriorityTask (includes priority levels), RecurringTask (repeats at defined intervals). Each subclass must override or extend base behaviors where appropriate."

models.py — Class Hierarchy

Task is the base class. The three subclasses use super().__init__() and each override to_dict() and __str__().

Base Class — Task

class Task:
  def __init__(self, title, description=""):
    if not title:
      raise InvalidTaskError("Title cannot be empty.")
    self.id = str(uuid.uuid4())[:8]
    self.title = title
    self.completed = False
    self.tags = set()

  def complete(self):
    self.completed = True

  def to_dict(self):  # overridden by each subclass
    return {"id": self.id, "title": self.title ...}

Three Derived Classes

class DeadlineTask(Task):
  def __init__(self, title, deadline=None):
    super().__init__(title)
    self.deadline = deadline  # new attribute

class PriorityTask(Task):
  LEVELS = ["low", "medium", "high", "critical"]
  def __init__(self, title, priority="medium"):
    super().__init__(title)
    self.priority = priority  # new attribute

class RecurringTask(Task):
  INTERVALS = ["daily", "weekly", "monthly"]
  def __init__(self, title, interval="weekly"):
    super().__init__(title)
    self.interval = interval  # new attribute
Requirement 3.3 — Design Patterns

Three design patterns implemented

One Creational, one Behavioral, and one Structural pattern — each in its own module.

Assignment says: "Creational Pattern: Factory Pattern for task creation. Behavioral Pattern: Observer Pattern for task updates/notifications. Structural Pattern: Decorator or Adapter Pattern for extending functionality."
Creational — factory.py

Factory Pattern

Creates task objects from a type string. Client code never instantiates classes directly.

# factory.py
TYPE_MAP = {
  "task": Task,
  "deadline": DeadlineTask,
  "priority": PriorityTask,
  "recurring": RecurringTask,
}

def create_task(task_type, **kwargs):
  cls = TYPE_MAP.get(task_type.lower())
  if cls is None:
    raise InvalidTaskError(...)
  return cls(**kwargs)
Behavioral — observer.py

Observer Pattern

EventManager notifies all subscribers whenever a task changes state.

# observer.py
class EventManager:
  def subscribe(self, listener):
    self._listeners.append(listener)

  def notify(self, event, task):
    for l in self._listeners:
      l.on_event(event, task)

class ConsoleListener:
  def on_event(self, event, task):
    print(f"[{event}] {task.title}")
Structural — decorator.py

Decorator Pattern

UrgentTask wraps any task and adds a label without modifying the original object.

# decorator.py
class UrgentTask:
  def __init__(self, task, label="URGENT"):
    self._task = task
    self._label = label

  @property
  def title(self):
    return f"[{self._label}] {self._task.title}"

  def complete(self):
    self._task.complete()  # delegates

3.6 — Custom Iterator

A class with __iter__ and __next__ that filters tasks based on a condition.

Assignment says: "A custom iterator must be implemented to traverse tasks based on specific conditions (e.g., incomplete tasks only)."

iterator.py — TaskIterator class

class TaskIterator:
  def __init__(self, tasks, condition=None):
    self._tasks = [
      t for t in tasks
      if condition is None or condition(t)
    ]
    self._index = 0

  def __iter__(self):
    return self

  def __next__(self):
    if self._index >= len(self._tasks):
      raise StopIteration
    task = self._tasks[self._index]
    self._index += 1
    return task

Two helper functions using the iterator

# Filter: incomplete tasks only
def incomplete_tasks(tasks):
  return TaskIterator(
    tasks, lambda t: not t.completed
  )

# Filter: tasks matching a specific tag
def tasks_by_tag(tasks, tag):
  return TaskIterator(
    tasks, lambda t: tag in t.tags
  )

# Used in manager.py
def incomplete(self):
  return list(incomplete_tasks(self._tasks))

3.7 — Regex Input Parsing

User input like "title:Homework due:2026-05-01 priority:high" is parsed with regular expressions.

Assignment says: "The system should parse structured user input using regular expressions. For example: title:Homework due:2026-05-01 priority:high"
# parser.py
import re

FIELD_RE = re.compile(r'(\w+):(\S+)')        # matches every key:value pair
DATE_RE  = re.compile(r'^\d{4}-\d{2}-\d{2}$')  # validates YYYY-MM-DD format

def parse_input(raw):
  matches = FIELD_RE.findall(raw)
  if not matches:
    raise InvalidTaskError("No valid fields. Use: title:MyTask priority:high")
  parsed = {k.lower(): v for k, v in matches}  # dict comprehension
  if "title" not in parsed:
    raise InvalidTaskError("Input must include a 'title' field.")
  return parsed

# Example: "title:Homework due:2026-05-01 priority:high"
# Returns:  {"title": "Homework", "due": "2026-05-01", "priority": "high"}

3.8 — JSON Serialization

Tasks are saved to and loaded from a JSON file so data persists between sessions.

Assignment says: "Tasks must be saved and loaded using a persistence mechanism: JSON or pickle format."

storage.py

def save_tasks(tasks, filepath="tasks.json"):
  with open(filepath, "w") as f:
    json.dump(
      [t.to_dict() for t in tasks],
      f, indent=2
    )

def load_tasks(filepath="tasks.json"):
  if not os.path.exists(filepath):
    return []
  with open(filepath, "r") as f:
    return [task_from_dict(d) for d in json.load(f)]
